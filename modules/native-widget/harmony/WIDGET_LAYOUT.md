# 课程卡片排版

参考：[福 uu 小组件](https://www.figma.com/design/OlQkTxYCJYesZg2lI65IAX?node-id=61-2379)，2026-10-21 只读核对。今日使用主课程样式，后续及明日课程使用 `Event / small`。排版参数集中在 `WidgetStyle.ets`，业务组件不再单独调整文字行高或负边距。

修改后如何利用本地缓存构建并更新模拟器，见 [HarmonyOS NEXT 本地构建与小组件样式迭代](../../../docs/build/harmony.md)。

| 层级                                    | Figma 间距 |
| --------------------------------------- | ---------- |
| 卡片内边距 / 双栏间距                   | 18 / 10    |
| 栏标题 → 课程列表                       | 8          |
| 课程 → 下一课程或剩余计数               | 4          |
| 主课程标题 → 备注、地点、时间组成的详情 | 6          |
| 紧凑课程标题 → 详情                     | 4          |
| 主课程详情各行                          | 4          |
| 紧凑课程地点 → 时间，横排及换行回退     | 2          |
| 指示条 → 内容容器                       | 2          |
| 内容容器上、下 / 左、右内边距           | 3 / 2      |

| 文字               | 字号 / 字重 | Figma 行高 | Figma 裁边后的单行框 |
| ------------------ | ----------- | ---------- | -------------------- |
| 主课程名           | 14 / 600    | 110%       | 12                   |
| 备注               | 10 / 600    | 100%       | 9，多行每行增加 10   |
| 主课程地点、时间   | 12 / 600    | 100%       | 10                   |
| 紧凑课程名         | 10 / 600    | 110%       | 9                    |
| 紧凑课程地点、时间 | 10 / 600    | 100%       | 9                    |
| 栏标题             | 12 / 600    | 100%       | 10                   |

鸿蒙卡片使用 `vp` 固定字号和行高。栏标题为 13 / 18，主课程名为 15 / 19，主课程地点和时间为 13 / 16，备注和紧凑课程等次要文字为 11 / 14。课名到详情、备注到地点均留 2vp，地点与时间分行时留 1vp。卡片横向、纵向内边距分别为 14vp、12vp，实际高度低于 140vp 时改为 12vp、8vp。

主课程备注最多显示 3 行。今日优先展示主课程、紧凑的下一节和剩余课数。空间不足时先省略两节之后的计数，下一节也放不下时用「其他 N 节课」表示全部后续课程。计数也放不下时只显示主课程。主课程仍放不下时，将备注缩减为 2、1、0 行，再将课名缩为一行。极矮时先隐藏地点和时间，单行课名也放不下时只显示栏标题。后续课程和明日课程使用紧凑样式，地点和时间同排放不下时将时间移到下一行。每种排版均以实际测得的内容高度判断是否放得下。

检查时应同时对照今日和明日两栏的字形间距，并覆盖两行课名、三行备注、长地点换行和矮卡片的内容回退。
