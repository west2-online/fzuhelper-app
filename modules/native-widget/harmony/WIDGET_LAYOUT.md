# 课程卡片排版

参考：[福 uu 小组件](https://www.figma.com/design/OlQkTxYCJYesZg2lI65IAX?node-id=61-2379)，2026-10-21 只读核对。今日使用主课程样式，后续及明日课程使用 `Event / small`。排版参数集中在 `WidgetStyle.ets`，业务组件不再单独调整文字行高或负边距。

修改后如何利用本地缓存构建并更新模拟器，见 [HarmonyOS NEXT 本地构建与小组件样式迭代](../../../docs/build/harmony.md)。

| 层级                                    | Figma 间距 |
| --------------------------------------- | ---------- |
| 卡片内边距 / 双栏间距                   | 18 / 10    |
| 栏标题 → 课程列表                       | 8          |
| 课程 → 下一课程或剩余计数               | 4          |
| 主课程标题 → 备注、地点、时间组成的详情 | 6          |
| 紧凑课程标题 → 详情                     | 4          |
| 主课程详情各行                          | 4          |
| 紧凑课程地点 → 时间，横排及换行回退     | 2          |
| 指示条 → 内容容器                       | 2          |
| 内容容器上、下 / 左、右内边距           | 3 / 2      |

| 文字               | 字号 / 字重 | Figma 行高 | Figma 裁边后的单行框 |
| ------------------ | ----------- | ---------- | -------------------- |
| 主课程名           | 14 / 600    | 110%       | 12                   |
| 备注               | 10 / 600    | 100%       | 9，多行每行增加 10   |
| 主课程地点、时间   | 12 / 600    | 100%       | 10                   |
| 紧凑课程名         | 10 / 600    | 110%       | 9                    |
| 紧凑课程地点、时间 | 10 / 600    | 100%       | 9                    |
| 栏标题             | 12 / 600    | 100%       | 10                   |

Figma 的 PingFang SC 与设备上的 HarmonyOS Sans 字形度量不同，不能把设计稿文字框高度直接当作原生文字高度，再从所有文字上减掉同一段留白。主课程名与备注保留原生行框；紧凑课程与地点、时间的行框补偿统一由 `WidgetTypography` 定义。文字参数使用 `fp`，容器间距使用 `vp`；换行仍由实际宽度和字体大小决定，不固定多行文字的高度。

根据 2026-10-21 的视觉反馈，含备注时将“标题 → 备注 / 备注 → 地点组”调整为 **2 / 4**，地点与时间之间调整为 **2**。在鸿蒙字体下，备注上下的可见留白接近，也为两行标题和三行备注保留空间。无备注时标题到地点组仍为 6；字号、字重和颜色不变。

主课程开启备注后最多显示 **3 行**，超出部分在第三行末尾省略。容量回退只折叠后续课程、改为剩余计数，必要时截短课程名，不减少备注行数。`Event / small`（后续及明日课程）不显示备注，也不参与备注判断。课程内部容器均以完整内容高度参与测量，避免先被父容器压缩，再被误判为能放下。

检查时应同时对照今日和明日两栏的可见字形间距，并覆盖两行课程名、三行备注、长地点换行，以及“下一节 → 其他 x 节课 → 仅当前课程”的容量回退。不能只确认容器的 `space` 数值或构建成功。
